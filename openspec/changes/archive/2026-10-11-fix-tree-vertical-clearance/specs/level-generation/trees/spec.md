## ADDED Requirements

### Requirement: Fixed tree height
Каждое сгенерированное дерево ДОЛЖНО иметь фиксированную высоту 400 пикселей от начала ствола до конца листвы, независимо от расположения платформ. Ствол ДОЛЖЕН составлять около 2/3 высоты, листва — около 1/3 (сохраняется пропорция «листва = ствол/2»). Допускается отклонение не более 2 пикселей из-за целочисленного округления.

#### Scenario: Tree height is fixed
- **WHEN** генератор размещает дерево
- **THEN** высота дерева от начала ствола до конца листвы равна 400 пикселям с точностью до округления (не более 2 пикселей)

#### Scenario: Trunk and leaves proportions
- **WHEN** дерево создается
- **THEN** высота ствола составляет около 2/3, а высота листвы — около 1/3 общей высоты дерева

### Requirement: Climbable tree ladder
Дерево ДОЛЖНО генерировать ветки-ступени только вдоль ствола (ветки НЕ ДОЛЖНЫ заходить в листву), равномерно распределённые по высоте ствола с вертикальным шагом не более высоты прыжка (110 пикселей), поочерёдно влево и вправо, так чтобы игрок мог подняться с блока земли до вершины ствола. Верхняя ветка ДОЛЖНА находиться у верхней грани ствола. Основание каждой ветки находится внутри x-диапазона ствола, а сама ветка выступает наружу.

#### Scenario: Branch vertical step within jump height
- **WHEN** генератор создает ветки-ступени
- **THEN** вертикальное расстояние между соседними ветками не превышает 110 пикселей

#### Scenario: Branches stay on the trunk
- **WHEN** дерево создается
- **THEN** ни одна ветка не располагается выше верхней грани ствола (ветки не выходят в листву)

#### Scenario: Top branch is at the trunk top
- **WHEN** дерево создается
- **THEN** верхняя ветка находится у верхней грани ствола

#### Scenario: Low branch is reachable from the block
- **WHEN** дерево создается
- **THEN** нижняя ветка находится на высоте не более 110 пикселей от основания ствола

#### Scenario: Sides alternate
- **WHEN** генератор создает ветки-ступени
- **THEN** соседние ветки выступают в противоположные стороны (влево и вправо поочерёдно)

#### Scenario: Several branches per side
- **WHEN** дерево создается в режиме лестницы
- **THEN** с одной стороны может выступать больше одной ветки

### Requirement: Reserved tree room
Генератор платформ ДОЛЖЕН работать снизу вверх и резервировать вертикальное пространство высотой 400 пикселей над каждым блоком земли, предназначенным для дерева: следующий блок земли над таким блоком размещается на расстоянии полной высоты дерева. Если дерево добавлено, зарезервированный блок-платформа ДОЛЖЕН находиться со стороны самой верхней ветки дерева. Ветки дерева ДОЛЖНЫ служить платформами и обеспечивать подъём через этот промежуток. Дерево ДОЛЖНО размещаться в зарезервированном пространстве и НЕ ДОЛЖНО пересекаться с блоками земли. Блоки земли при этом НЕ ДОЛЖНЫ перемещаться.

#### Scenario: Room is reserved for a tree
- **WHEN** генератор размещает блок, предназначенный для дерева
- **THEN** следующий блок земли над ним находится на расстоянии не менее высоты дерева (400 пикселей)

#### Scenario: Platform is on the top branch side
- **WHEN** дерево добавлено и над его блоком есть зарезервированная платформа
- **THEN** платформа расположена слева или справа от блока со стороны самой верхней ветки дерева

#### Scenario: Tree fits without intersecting platforms
- **WHEN** генератор размещает дерево
- **THEN** над стволом на высоту 400 пикселей нет блоков земли, перекрывающих ствол по x

#### Scenario: Branches bridge the reserved gap
- **WHEN** игрок поднимается по дереву
- **THEN** ветки-ступени позволяют добраться до блока земли над деревом

#### Scenario: Platforms are not moved
- **WHEN** генератор размещает деревья
- **THEN** ни один блок земли не изменяет свою позицию

## MODIFIED Requirements

### Requirement: One branch per side
Дерево, создаваемое в обычном режиме, ДОЛЖНО иметь не более одной ветки с каждой стороны ствола: не более одной слева и не более одной справа. Дерево, создаваемое в режиме лестницы (с шагом веток), МОЖЕТ иметь несколько веток с каждой стороны.

#### Scenario: At most one branch per side
- **WHEN** дерево создается в обычном режиме
- **THEN** количество веток, выступающих влево, не превышает одной, и количество веток, выступающих вправо, не превышает одной

#### Scenario: One branch on each side
- **WHEN** дерево создается в обычном режиме с числом веток не менее двух
- **THEN** слева выступает ровно одна ветка и справа выступает ровно одна ветка

#### Scenario: Ladder mode allows several branches per side
- **WHEN** дерево создается в режиме лестницы
- **THEN** количество веток, выступающих влево или вправо, может быть больше одной
