## MODIFIED Requirements

### Requirement: Platform vertical spacing
Генератор уровней ДОЛЖЕН создавать блоки земли varying длины, увеличенной в случайное число раз (1.2-2.0). Вертикальное расстояние между блоками НЕ ДОЛЖНО превышать высоту двойного прыжка за вычетом высоты персонажа (110 пикселей), за исключением блоков, несущих дерево: над таким блоком резервируется полная высота дерева (400 пикселей), которую игрок преодолевает по веткам дерева.

#### Scenario: Ground block length variation
- **WHEN** генератор создает блоки земли
- **THEN** базовая длина блока составляет от 3 до 10 тайлов, умножается на случайный коэффициент 1.2-2.0, при этом длинных блоков (больше 5 тайлов) больше, чем коротких

#### Scenario: Ground block vertical placement
- **WHEN** генератор размещает блоки земли, не несущие дерево
- **THEN** вертикальное расстояние между блоками не превышает высоту двойного прыжка минус высота персонажа (110 пикселей)

#### Scenario: Tree-carrying block reserves room
- **WHEN** генератор размещает блок, несущий дерево
- **THEN** следующий блок земли над ним находится на расстоянии не менее 400 пикселей, а промежуток преодолевается по веткам дерева

### Requirement: Reachable upward neighbor for every block
Для каждого сгенерированного блока земли генератор ДОЛЖЕН гарантировать наличие блока выше, до которого игрок может добраться. Блок-сосед размещается слева или справа от исходного блока, а горизонтальный зазор между ними НЕ ДОЛЖЕН превышать максимальную горизонтальную дистанцию, преодолеваемую игроком во время прыжка (вычисляется из горизонтальной скорости и длительности прыжка персонажа `Shooter`). Обычный блок достигается одним прыжком (не более 110 пикселей по вертикали); блок, несущий дерево, может находиться на высоте дерева (400 пикселей) и достигается по веткам дерева, которые служат платформами.

#### Scenario: Neighbor exists for every block
- **WHEN** генератор создает блок земли
- **THEN** выше этого блока существует блок земли, достижимый с исходного блока прыжком или по веткам дерева

#### Scenario: Neighbor placed left or right
- **WHEN** генератор размещает блок-сосед выше
- **THEN** сосед расположен слева или справа от исходного блока

#### Scenario: Horizontal gap within jump reach
- **WHEN** генератор размещает блок-сосед
- **THEN** горизонтальный зазор между исходным блоком и соседом не превышает максимальной горизонтальной дистанции прыжка

#### Scenario: Neighbor respects minimum spacing
- **WHEN** генератор размещает блок-сосед
- **THEN** горизонтальный зазор между исходным блоком и соседом не меньше минимального зазора между блоками (2 ширины персонажа `Shooter`)

#### Scenario: Tree bridges a tall gap
- **WHEN** блок земли несёт дерево
- **THEN** его верхний сосед может находиться на высоте дерева, и игрок поднимается к нему по веткам дерева

### Requirement: Climbable path from start block
Генератор ДОЛЖЕН обеспечивать, чтобы начиная со стартового блока игрок мог последовательно подниматься по достижимым блокам-соседям (или по веткам деревьев, если блок несёт дерево) до верхней части уровня, не имея между соседними блоками недостижимых разрывов.

#### Scenario: Climb from start block to top
- **WHEN** уровень сгенерирован
- **THEN** существует последовательность достижимых блоков от стартового блока до самого верхнего блока уровня, где блоки с деревьями преодолеваются по веткам

#### Scenario: No unreachable gap between adjacent levels
- **WHEN** генератор размещает блоки на двух соседних вертикальных уровнях
- **THEN** у каждого блока нижнего уровня есть достижимый блок на верхнем уровне (прыжком или по веткам дерева)
