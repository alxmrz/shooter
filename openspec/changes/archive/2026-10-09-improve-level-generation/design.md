## Context

Текущая система генерации уровней (`LevelGenerator`) создает простые платформы фиксированного размера (100x25) и размещает врагов в случайных позициях без учета физики. Это приводит к нереалистичному поведению (падение врагов) и ограниченному игровому опыту.

## Goals / Non-Goals

**Goals:**
- Заменить платформы на блоки земли varying длины (3-10 тайлов)
- Добавить генерацию деревьев с ветками как платформами
- Обеспечить размещение врагов на твердых поверхностях
- Сохранить совместимость с существующей системой Map и Fabric

**Non-Goals:**
- Изменять основные физические константы (размер тайлов, высота прыжка)
- Добавлять новые типы объектов除了 деревьев
- Изменять систему рендеринга или камеры

## Decisions

### 1. Структура блоков земли
**Решение:** Использовать существующий класс `Platform` для блоков земли, но с varying длиной.

**Альтернативы:**
- Создать новый класс `GroundBlock` - избыточно, так как `Platform` уже реализует нужное поведение
- Использовать `Border` - не подходит, так как `Border` не имеет физики столкновений

**Обоснование:** `Platform` уже имеет нужную физику (столкновения, платформа). Изменение размера не требует нового класса.

### 2. Представление деревьев
**Решение:** Создать новый класс `Tree`, который будет генерировать ствол и ветки как отдельные `Platform` объекты.

**Альтернативы:**
- Сделать дерево одним объектом - сложно, так как ветки должны быть отдельными платформами
- Использовать составной объект - перегрузка, так как ветки уже являются платформами

**Обоснование:** Каждая ветка должна быть отдельной платформой для физики столкновений. Ствол может быть декоративным или также платформой.

### 3. Алгоритм генерации блоков земли
**Решение:** Заменить `generatePlatforms()` на `generateGroundBlocks()` с алгоритмом:
1. Начинаем с нижней границы (y=2950)
2. Генерируем блоки varying длины (3-10 тайлов)
3. Длинные блоки (6-10) появляются чаще (60% вероятность)
4. Блоки размещаются на фиксированной высоте (уровень земли) или на разных уровнях с учетом maxHeight прыжка

**Альтернативы:**
- Случайное размещение без учета расстояния - приведет к недостижимым платформам
- Фиксированные интервалы - слишком предсказуемо

**Обоснование:** Алгоритм обеспечивает проходимость уровня и разнообразие.

### 4. Размещение врагов
**Решение:** Изменить `generateEnemies()` для проверки наличия платформы под врагом:
1. Сначала генерируем все платформы и блоки земли
2. Для каждого врага выбираем случайную платформу
3. Размещаем врага на платформе (y - высота врага)
4. Проверяем, что враг не в области видимости камеры

**Альтернативы:**
- Размещать врагов после всех объектов - может привести к перекрытию
- Использовать простой random без проверки - враги будут падать

**Обоснование:** Гарантирует, что враги всегда на твердой поверхности.

### 5. Генерация деревьев
**Решение:** Добавить метод `generateTrees()`:
1. Определяем количество деревьев (5-15 в зависимости от ширины уровня)
2. Для каждого дерева:
   - Выбираем случайную позицию x
   - Создаем ствол (декоративный или как платформу)
   - Генерируем 2-4 ветки на разной высоте
   - Ветки are платформы varying длины (2-6 тайлов)

**Альтернативы:**
- Фиксированное количество деревьев - менее разнообразно
- Только визуальные деревья без платформ - не соответствует требованиям

**Обоснование:** Обеспечивает разнообразие и игровую механику с прыжками на ветки.

## Risks / Trade-offs

**Риск:** Увеличение количества объектов может повлиять на производительность.
**Митигация:** Ограничить максимальное количество деревьев и веток, оптимизировать проверку столкновений.

**Риск:** Сложность генерации проходимых уровней с деревьями.
**Митигация:** Тестировать алгоритм генерации, обеспечить connectivity между платформами.

**Риск:** Совместимость с существующими тестами.
**Митигация:** Обновить тесты для покрытия новой функциональности, сохранить старые тесты для регрессии.

## Migration Plan

1. Модифицировать `LevelGenerator::generatePlatforms()` для генерации блоков земли
2. Добавить метод `generateTrees()` и интегрировать в `generateLevel()`
3. Изменить `generateEnemies()` для размещения на платформах
4. Обновить тесты для покрытия новой функциональности
5. Проверить совместимость с существующими уровнями
