## Purpose

Генерация деревьев с ветками для создания разнообразных платформ в уровне.

## Requirements

### Requirement: Tree structure
Деревья ДОЛЖНЫ состоять из ствола, веток и листвы, где ветки функционируют как платформы.

#### Scenario: Tree components
- **WHEN** дерево создается
- **THEN** оно состоит из вертикального ствола, горизонтальных веток и листвы

#### Scenario: Branch as platform
- **WHEN** игрок стоит на ветке дерева
- **THEN** ветка ведет себя как платформа (игрок может ходить по ней и прыгать с нее)

### Requirement: Tree generation
Деревья ДОЛЖНЫ генерироваться автоматически на уровне.

#### Scenario: Tree placement
- **WHEN** генератор создает дерево
- **THEN** дерево размещается на блоке земли или рядом с ним

#### Scenario: Tree count
- **WHEN** генератор создает уровень
- **THEN** количество деревьев варьируется в зависимости от размера уровня

### Requirement: Branch variation
Ветки деревьев ДОЛЖНЫ крепиться основанием внутри x-диапазона ствола, выступать наружу влево или вправо и иметь разную длину и положение.

#### Scenario: Branch length variation
- **WHEN** генератор создает ветки
- **THEN** длина веток варьируется (например, от 2 до 6 тайлов)

#### Scenario: Branch placement within trunk
- **WHEN** генератор размещает ветку
- **THEN** основание ветки находится в пределах x-диапазона ствола `[trunkX, trunkX + W]`, а сама ветка выступает наружу

#### Scenario: Branch height variation
- **WHEN** генератор размещает ветки
- **THEN** ветки размещаются на разной высоте относительно ствола

### Requirement: Tree bounding box
Дерево ДОЛЖНО быть единым объектом с ненулевыми границами, покрывающими ствол, ветки и листву, и ДОЛЖНО отрисовываться, когда его часть попадает в видимую область.

#### Scenario: Non-zero bounds
- **WHEN** дерево создается
- **THEN** его границы (width и height) не равны нулю и охватывают все части дерева

#### Scenario: Rendering in view
- **WHEN** любая часть дерева попадает в видимую область
- **THEN** дерево отрисовывается, и ствол, ветки и листва видны

### Requirement: Trunk geometry
Ствол дерева ДОЛЖЕН быть вертикальным прямоугольником шириной `W` и высотой `H`, ДОЛЖЕН начинаться от базовой точки `y` и расти вверх, и НЕ ДОЛЖЕН иметь коллизий.

#### Scenario: Trunk dimensions
- **WHEN** дерево создается
- **THEN** ствол имеет ширину `W` и высоту `H` и расположен от `y` вверх

#### Scenario: Trunk has no collision
- **WHEN** игрок пересекает ствол
- **THEN** ствол не блокирует движение игрока

### Requirement: Tree placement constraints
Генератор ДОЛЖЕН размещать не более одного дерева в каждом 500-пиксельном сегменте ширины уровня, а ствол дерева ДОЛЖЕН располагаться не ближе 200 пикселей к правому краю своего 500-пиксельного сегмента.

#### Scenario: At most one tree per 500 pixels
- **WHEN** генератор размещает деревья
- **THEN** в каждом 500-пиксельном сегменте ширины уровня находится не более одного ствола дерева

#### Scenario: Trunk offset from segment right edge
- **WHEN** генератор размещает ствол дерева в сегменте шириной 500 пикселей
- **THEN** координата X ствола не превышает начала сегмента плюс 300 пикселей, то есть ствол не ближе 200 пикселей к правому краю сегмента

#### Scenario: First tree placement
- **WHEN** генерируется первое дерево
- **THEN** координата X его ствола находится в диапазоне от 0 до 300 пикселей

### Requirement: Leaves geometry
Листва ДОЛЖНА быть единым прямоугольным объектом шириной `7·W` и высотой `H/2`, с началом по X в `trunkX − 3·W`, и НЕ ДОЛЖНА иметь коллизий.

#### Scenario: Leaves rectangle
- **WHEN** дерево создается
- **THEN** листва представляет собой единый прямоугольник шириной `7·W` и высотой `H/2`

#### Scenario: Leaves position
- **WHEN** дерево создается
- **THEN** координата X начала листвы равна `trunkX − 3·W`

#### Scenario: Leaves have no collision
- **WHEN** игрок пересекает листву
- **THEN** листва не блокирует движение игрока

### Requirement: One branch per side
Дерево ДОЛЖНО иметь не более одной ветки с каждой стороны ствола: не более одной слева и не более одной справа.

#### Scenario: At most one branch per side
- **WHEN** дерево создается
- **THEN** количество веток, выступающих влево, не превышает одной, и количество веток, выступающих вправо, не превышает одной

#### Scenario: One branch on each side
- **WHEN** дерево создается с числом веток не менее двух
- **THEN** слева выступает ровно одна ветка и справа выступает ровно одна ветка
