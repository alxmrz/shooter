## Purpose

Автоматическая генерация уровней с платформами, предметами и врагами для увеличения реиграбельности и ускорения разработки.

## Requirements

### Requirement: Level dimensions
Генератор уровней ДОЛЖЕН создавать уровни фиксированного размера 3000x3000 пикселей.

#### Scenario: Standard level size
- **WHEN** генератор создает новый уровень
- **THEN** размер уровня составляет 3000x3000 пикселей

### Requirement: Platform vertical spacing
Генератор уровней ДОЛЖЕН создавать блоки земли varying длины, увеличенной в случайное число раз (1.2-2.0), и вертикальное расстояние между блоками НЕ ДОЛЖНО превышать высоту двойного прыжка за вычетом высоты персонажа (110 пикселей).

#### Scenario: Ground block length variation
- **WHEN** генератор создает блоки земли
- **THEN** базовая длина блока составляет от 3 до 10 тайлов, умножается на случайный коэффициент 1.2-2.0, при этом длинных блоков (больше 5 тайлов) больше, чем коротких

#### Scenario: Ground block vertical placement
- **WHEN** генератор размещает блоки земли
- **THEN** вертикальное расстояние между блоками не превышает высоту двойного прыжка минус высота персонажа (110 пикселей)

### Requirement: Random item placement
Кристаллы, здоровье и патроны ДОЛЖНЫ размещаться в случайных позициях на уровнях.

#### Scenario: Crystals distribution
- **WHEN** генератор размещает кристаллы
- **THEN** кристаллы находятся в случайных позициях на платформах или в воздухе

#### Scenario: Health items distribution
- **WHEN** генератор размещает здоровье
- **THEN** предметы здоровья находятся в случайных позициях на платформах или в воздухе

#### Scenario: Ammunition distribution
- **WHEN** генератор размещает патроны
- **THEN** патроны находятся в случайных позициях на платформах или в воздухе

### Requirement: Enemy placement constraints
Враги (Shooter) ДОЛЖНЫ размещаться в случайных позициях, но НЕ в области видимости игрока, и ДОЛЖНЫ появляться на твердых поверхностях (блоки земли, платформы).

#### Scenario: Enemy visibility constraint
- **WHEN** генератор размещает врага
- **THEN** враг находится за пределами видимости камеры игрока (вне текущего экрана)

#### Scenario: Enemy spawn on solid surface
- **WHEN** генератор размещает врага
- **THEN** враг появляется на твердой поверхности (блок земли или платформа) и не падает при появлении

#### Scenario: Enemy count limit
- **WHEN** генератор создает уровень
- **THEN** количество врагов на карте не превышает 10

#### Scenario: Random enemy positioning
- **WHEN** генератор размещает врагов
- **THEN** позиции врагов выбираются случайным образом в пределах уровня

### Requirement: Ground platform
Генератор ДОЛЖЕН создавать nền (ground) по нижней границе уровня.

#### Scenario: Ground generation
- **WHEN** генератор создает уровень
- **THEN** по нижней границе уровня (y=2950) создается сплошная платформа

### Requirement: Ground block generation
Генератор ДОЛЖЕН создавать сплошную землю по нижней границе уровня.

#### Scenario: Continuous ground
- **WHEN** генератор создает уровень
- **THEN** по нижней границе уровня создается сплошная земля из блоков varying длины

#### Scenario: Ground block length distribution
- **WHEN** генератор распределяет длины блоков
- **THEN** количество длинных блоков (больше 5 тайлов) превышает количество коротких блоков

### Requirement: At least one ground block per level
Генератор ДОЛЖЕН создавать не менее одного блока земли на каждом вертикальном уровне, на котором есть блоки. Ограничение «ровно один блок земли на уровне» снимается, поэтому на одном уровне может находиться несколько блоков.

#### Scenario: At least one block per level
- **WHEN** генератор создает блоки земли
- **THEN** на каждом вертикальном уровне, где есть блоки, размещается не менее одного блока земли

#### Scenario: Multiple blocks allowed on a level
- **WHEN** для блока земли создаётся сосед на уровень выше
- **THEN** на этом уровне появляется дополнительный блок, и число блоков на уровне может быть больше одного

### Requirement: Reachable upward neighbor for every block
Для каждого сгенерированного блока земли генератор ДОЛЖЕН гарантировать наличие блока на следующем уровне выше, до которого игрок может добраться прыжком. Блок-сосед размещается слева или справа от исходного блока, а горизонтальный зазор между ними НЕ ДОЛЖЕН превышать максимальную горизонтальную дистанцию, преодолеваемую игроком во время прыжка (вычисляется из горизонтальной скорости и длительности прыжка персонажа `Shooter`).

#### Scenario: Neighbor exists for every block
- **WHEN** генератор создает блок земли
- **THEN** на уровень выше этого блока существует блок земли, достижимый с исходного блока прыжком

#### Scenario: Neighbor placed left or right
- **WHEN** генератор размещает блок-сосед на уровень выше
- **THEN** сосед расположен слева или справа от исходного блока

#### Scenario: Horizontal gap within jump reach
- **WHEN** генератор размещает блок-сосед
- **THEN** горизонтальный зазор между исходным блоком и соседом не превышает максимальной горизонтальной дистанции прыжка

#### Scenario: Neighbor respects minimum spacing
- **WHEN** генератор размещает блок-сосед
- **THEN** горизонтальный зазор между исходным блоком и соседом не меньше минимального зазора между блоками (2 ширины персонажа `Shooter`)

### Requirement: Climbable path from start block
Генератор ДОЛЖЕН обеспечивать, чтобы начиная со стартового блока игрок мог последовательно подниматься по достижимым блокам-соседям до верхней части уровня, не имея между соседними уровнями недостижимых горизонтальных разрывов.

#### Scenario: Climb from start block to top
- **WHEN** уровень сгенерирован
- **THEN** существует последовательность достижимых блоков от стартового блока до самого верхнего блока уровня

#### Scenario: No unreachable gap between adjacent levels
- **WHEN** генератор размещает блоки на двух соседних вертикальных уровнях
- **THEN** у каждого блока нижнего уровня есть достижимый блок на верхнем уровне

### Requirement: Fixed starting ground block
Генератор ДОЛЖЕН создавать блок земли в нижнем левом углу карты всегда в одной и той же позиции и размещать на нём персонажа игрока.

#### Scenario: Start block position
- **WHEN** генерируется уровень
- **THEN** в нижнем левом углу создаётся блок земли фиксированного размера и позиции

#### Scenario: Player spawns on start block
- **WHEN** создаётся персонаж игрока
- **THEN** персонаж размещается на верхней грани стартового блока земли

### Requirement: Ground block minimum spacing
Генератор ДОЛЖЕН располагать блоки земли так, чтобы зазор между любыми двумя блоками был не меньше 2 ширин персонажа `Shooter` (100 пикселей) по горизонтали или не меньше 2 высот персонажа `Shooter` (100 пикселей) по вертикали. Иными словами, прямоугольники блоков, расширенные на половину требуемого зазора (50 пикселей с каждой стороны), НЕ ДОЛЖНЫ пересекаться.

#### Scenario: Horizontal clearance between blocks on the same level
- **WHEN** генератор размещает два блока земли на одной высоте
- **THEN** горизонтальный зазор между их границами не меньше 2 ширин персонажа (100 пикселей)

#### Scenario: Vertical clearance between overlapping blocks
- **WHEN** генератор размещает блок земли, горизонтальный диапазон которого пересекается с другим блоком
- **THEN** вертикальный зазор между их границами не меньше 2 высот персонажа (100 пикселей)

#### Scenario: Diagonal clearance
- **WHEN** генератор размещает два блока земли, не пересекающихся ни по одной из осей
- **THEN** зазор между ними не меньше 100 пикселей хотя бы по одной из осей, так что расширенные прямоугольники не пересекаются

#### Scenario: No pair of blocks is too close
- **WHEN** генератор создает уровень
- **THEN** ни одна пара блоков земли не пересекается и не имеет зазор меньше требуемого

### Requirement: Non-quadratic spacing check
Генератор ДОЛЖЕН обеспечивать минимальный зазор между блоками земли без попарного перебора всех блоков, то есть без сложности O(n²).

#### Scenario: Only nearby blocks are checked
- **WHEN** генератор размещает новый блок земли
- **THEN** проверяются только блоки из соседних пространственных областей, а не все ранее размещенные блоки

#### Scenario: Linear growth of proximity checks
- **WHEN** число размещаемых блоков земли увеличивается
- **THEN** количество проверок расстояния растёт не квадратично относительно числа блоков

### Requirement: Tree generation
Генератор ДОЛЖЕН создавать деревья с ветками, по которым можно ходить.

#### Scenario: Tree structure
- **WHEN** генератор создает дерево
- **THEN** дерево состоит из ствола и веток, которые функционируют как платформы

#### Scenario: Tree placement
- **WHEN** генератор размещает деревья
- **THEN** деревья размещаются на блоках земли или рядом с ними

#### Scenario: Branch walkability
- **WHEN** игрок стоит на ветке дерева
- **THEN** ветка ведет себя как платформа (игрок может ходить по ней и прыгать с нее)

### Requirement: Integration with Map system
Генератор ДОЛЖЕН интегрироваться с существующей системой Map для загрузки сгенерированных уровней.

#### Scenario: Level loading via Map
- **WHEN** генератор создает уровень
- **THEN** уровень загружается через существующий интерфейс Map::generateLevel

#### Scenario: Object creation via Fabric
- **WHEN** генератор создает объекты уровня
- **THEN** объекты создаются через существующий Fabric для обеспечения совместимости
